An award-winning, cinematic digital marketing agency web experience built for **SARVX.MEDIA**, inspired by the visual rhythm, scroll choreography, and editorial aesthetics of Elva Labs.

---

## ⚡ Architectural Highlights

1. **Lenis + GSAP ScrollTrigger Global Pipeline**:
   - Scrubbed scroll-driven storytelling where scrolling feels like controlling a film.
   - Pinned Hero scene with 4-phase typography choreography and visual scaling.
   - Multi-speed vertical parallax editorial section (`WHO` / `WE` / `ARE`).

2. **1 / 6 Signature Interactive Approach System**:
   - Pinned full-viewport transformation across 6 stages:
     - `01 / 06 STRATEGY`
     - `02 / 06 CREATIVE`
     - `03 / 06 CONTENT`
     - `04 / 06 DISTRIBUTION`
     - `05 / 06 PERFORMANCE`
     - `06 / 06 GROWTH`

3. **High-Contrast Dark Editorial Aesthetic**:
   - `#000000` deep black ground with silver/white display typography.
   - Zero gradient blobs or cliché SaaS cards.
   - Custom magnetic cursor with state morphing (`VIEW`, `EXPLORE`, magnetic button physics).
   - Ethereal ambient sound synthesizer built on Web Audio API (toggleable).

4. **18+ Comprehensive Narrative Sections**:

   - **Content & Creative**: Film-grain cinematic canvas.
   - **Web Experiences**: 3D perspective device showcase.
   - **Selected Case Studies**: Fullscreen layered stacking cards (Aetheria, Monolith, Synapse, Lumen).
   - **Why SARVX**: 5 enterprise pillars.

   - **Project Inquiry Drawer**: Modal form with instant submission feedback.

## 🚀 How to Run Locally

You can open `index.html` directly in any modern browser, or run a local HTTP server:

```bash
# Python 3
python3 -m http.server 3000

# or Node / npx
npx serve .
```

Navigate to `http://localhost:3000` to experience the 60fps cinematic journey.
